# Security policy

**Ox of Hephaestus is an early-stage experimental fork.** It has not published independent supported release versions, a security-update schedule, or a vulnerability-response SLA. A version number inherited from Evennia must not be taken as a promise of Ox-specific security maintenance.

## Reporting vulnerabilities

- **In unmodified Evennia:** follow the [upstream Evennia vulnerability-reporting process](https://github.com/evennia/evennia/security) so the engine's maintainers can investigate.
- **In Ox-specific additions or integrations:** use GitHub's private vulnerability reporting for this repository **if it is enabled**. Do not publish exploit details or credentials in a public issue. If no private reporting channel is available, open a nonsensitive issue requesting a private disclosure route without including the vulnerability itself.

For the current scope of this fork, see [README.md](README.md). Production deployment and security hardening have not yet been claimed or documented for Ox.
