# G3e-1 — Anomaly without an oracle

This is a bounded, opt-in experimental investigation for the **existing five crew**, not a new personality or compartment. The operator arms one open anomaly with `world.investigation.arm_anomaly()`, optionally specifying `cause` and `seed` for disposable test reproducibility. Neither the ordinary bootstrap nor idle operation injects an incident. The hidden case contains one of three causes: cargo vapors, scrubber bypass, or bus interference.

**Epistemic contract.** All five receive a symptom-only notice. Each separately chooses whether to investigate. Its authenticated character must physically reach its own station and invoke `oxsample <case-id>`. Lin observes analyzer disagreement; Ari drive-bus ripple; Iona an independent thermal witness; Mara cargo headspace trace; Teo scrubber intake delta. The world samples each station from overlapping conditional distributions: no individual baseline/elevated indication uniquely identifies the cause. Repeated sampling returns the same persisted evidence, not a new random draw. The latent cause and other private samples never appear in the actor's data feed.

A member can submit `oxwork <id> anomaly_report ship <case-id>` only after firsthand local sampling. The world records one actor-specific immutable WorkReceipt and two addressed events: a report receipt to the author and a measurements-only report to Lin. This does not merge character memories. The case report cannot be forged from another actor's dialogue. Ordinary role/location checks and the existing world work ledger gate each attempt.

Once Lin's own report and at least one verified engineering and specialist report exist, the bridge may send `oxwork <id> anomaly_assess ship <case-id> <cargo_vapors|scrubber_bypass|bus_interference>`. The supervisor offers all three choices **plus defer** to Lin's own Concordia entity. The choice is strictly a hypothesis, tagged `unconfirmed`; the GM does not reveal whether it matches the hidden cause, automatically close the case, order an intervention, or rewrite a belief as verified knowledge. Wrong hypotheses are allowed and retained.

The normal five-crew event dispatcher considers this work only when `OX_G3E_INVESTIGATION=1`, after urgent incidents, hails and watch obligations, before G3d optional wear rounds. A separate bounded `investigation-drain` command is for reproducible CI. It uses existing GOAP travel, five independently authenticated sessions, case-specific persisted reports and the global durable intent/receipt reconciliation protocol. No unconditional model polling occurs when idle.

**Limits:** the local signals are synthetic but stochastic, conditional on one hidden cause; this is not high-fidelity atmospheric physics. The deterministic test model's first-choice selection is integration evidence, not proof that a live language model reasons expertly. There is no automatic scientific falsification, multi-round experimental design, peer argumentation, or intervention outcome yet. The next increment should let actors challenge an explanation with new tests without leaking the world cause.

**Verification:** `game/world/tests/test_investigation.py` covers initial secrecy, actor-local sampling, duplicate readings, wrong hypotheses, and rollback of an interrupted report. `.github/workflows/ox-g3e-investigation.yml` tests this against the real world and the real five-client handler; a green final-head CI verdict is required before merging.
