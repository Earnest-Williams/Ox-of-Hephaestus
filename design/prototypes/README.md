# Ox prototype and experiment history

**Historical research index — 30 October 2026.** The files in this directory are stage-specific designs, preregistrations, observations and model experiments. Their original dates, unresolved questions and acceptance language are retained as evidence of the work **at that time**, not as a live statement about the merged ship.

Use [current implementation status](../STATUS.md), [current roadmap](../ROADMAP.md) and [current architecture](../../ARCHITECTURE.md) before planning new work. For the installed ship, [G19 acceptance](../ship/G19_ACCEPTANCE_RECORD_2026-10-29.md) supersedes earlier G17/G18 milestone wording.

## Record groups

- **P1–P4 and G1–G3:** independent agents, authenticated session transport, event journaling, durable work receipts, local capability discovery, the original seven-room proving ground and cooperation.
- **G4–G5:** character traits, world-owned skills, knowledge, receipt-backed experience, investigative learning and adversarial recoveries.
- **G6–G10:** crisis fixtures, social GOAP, private memories, world-clock semantics and authenticated state.
- **G11–G16:** native model-choice evaluations, position balance, personality routing proposals, CPU throughput and admission experiments. The dated results are not approval to enable experimental runtime flags.
- **P4f evidence follow-ups:** indexed archives, replay, cache integrity, cold storage and restart measurements.

These documents intentionally remain at their original stable paths so citations from PRs, code comments and decisions continue to resolve. A new implementation should link its own final-head acceptance evidence, rather than promoting a proposal or preliminary experiment result into a current capability.
